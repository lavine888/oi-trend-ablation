## 一句话结论

在 36 个境内商品期货主力连续序列上，把「持仓量同向扩张」作为唯一新增条件加到一条纯价格趋势
基线上，**样本外扣费后没有变好**：

| 指标（OOS 2022–2025，扣费 5bp） | 纯趋势 B0 | +持仓确认门 B1 |
|---|---:|---:|
| 年化 Sharpe | −0.005 | **−0.033** |
| 年化波动 | 7.2% | 4.1% |
| 最大回撤 | −17.7% | −10.1% |
| 年换手 | 13.6 | **26.7** |
| **ΔSharpe** | — | **−0.028** |

**盈亏平衡成本 4.4bp/单边**——低于商品期货的现实摩擦（手续费 + 一跳滑点通常 ≥5bp）。
换句话说：这个门只在"成本几乎为零"的世界里看起来有效，实盘不可交易。

> 记账口径：波动与回撤确实变好了，但那是**暴露减半**的机械结果；同样的效果直接把 B0 乘
> 0.56 倍杠杆就能拿到，还不用多付那一倍的换手成本。

**换样本还是负的。** 用完全相同的参数：

- **CFFEX 股指/国债**（IC/IF/IH/TF/T，2016–2025）：ΔSharpe = **−0.165**，2bp/5bp/10bp 三个成本档全负。
- **2010–2015 商品期货**（16 品种，IS 2010–2012 / OOS 2013–2015）：ΔSharpe = **−1.197**。
  这一段尤其关键——**纯趋势基线本身是赚钱的**（OOS +0.512），加上门之后变成 −0.685。

**但成本口径会翻转符号。** 换成逐品种费率后：手续费+1 跳（中位 3.47bp）下 Δ ≈ **+0.05**（等于零），
仅手续费（0.50bp）下 Δ ≈ **+0.18**，手续费+2 跳（6.42bp）下 Δ ≈ **−0.09**。
Δ 随成本线性变化、在 **≈4.4bp** 处过零——这正是主研究算出的盈亏平衡点。

所以本仓库的主张是精确的：**门不提供信息**（这一点有六条独立证据），
**它的净效果只是把换手翻倍后的成本算术**；只有在成本 ≥4.4bp 时才为负，在基线有效的样本里才造成实质损害。

## 为什么把负结果单独开源

负结果常常被埋掉，于是每个人都在同一个坑里重复交学费。这个仓库把整个过程摊开：

- **预注册先行**：假设、口径、判定档位在看到任何绩效**之前**写死，`sha256` 冻结，交付脚本会校验它没被事后改动。
- **只改一个变量**：B1 与 B0 的差别只有一道持仓确认门，不是多因子加权、不是调参、不是换宇宙。
- **四条独立判据同向**：IC、条件收益、置换检验、参数邻域，全部指向"这门没有筛选能力"。
- **把边界量化**：换月污染有多大、成本多高就失效、多少格参数邻域为正。
- **一条命令复现**：从平台取数到报告填表到门禁检查，全部脚本化。

## 复现：换资产类别 / 换时间段

主结果之后补做（**不是预注册内容**），目的只有一个：排除"负结果只是商品期货的样本特性"。

| 复现 | 品种 | OOS B0 | OOS B1 | **Δ** | 2bp / 10bp |
|---|---|---:|---:|---:|---|
| 换资产类别（CFFEX 股指/国债） | IC/IF/IH/TF/T | −0.139 | −0.304 | **−0.165** | −0.089 / −0.291 |
| 换时间段（2010–2015 商品） | 16 个 | **+0.512** | **−0.685** | **−1.197** | −1.022 / −1.485 |

两次复现都用同一套参数、同样的 IS/OOS 结构与 5bp 成本。2010–2015 那次最有说服力：
**基线本身是赚钱的（+0.512），门把它打到 −0.685** —— 说明在基线有效时，门造成了实质损害。

## 持仓数据的另外五种用法

把同一份持仓数据换五种构造，其余不动——回答"是不是构造没选对"：

| 构造 | OOS Sharpe | Δ vs B0 |
|---|---:|---:|
| V1 原始确认门 | −0.033 | −0.028 |
| V2 强确认门（同向且 \|ΔOI\| 分位 ≥50%） | +0.046 | +0.050 |
| V3 持仓高位门 | −0.340 | −0.335 |
| V4 反向门（背离才持仓） | −0.429 | −0.424 |
| V5 仅持仓变化（不用价格） | −0.148 | −0.143 |
| V6 持仓变化横截面极值 | −0.267 | −0.262 |

没有一个构造越过 +0.10 的弱正门槛；最好的 V2 是 +0.05，且把 IS Sharpe 从 0.63 压到 0.13——
五个变体里挑最好的，+0.05 完全在噪声范围内。V4 反向门更差，说明不是符号写反；
V5 说明持仓变化本身没有独立 alpha。

## 逐品种费率

乘数取自平台 `get_future_detail`（可核），最小变动价位与手续费来自公开资料（标注置信度：
高 24 / 中 11 / 低 1），明细见 [`references/fee_schedule.csv`](references/fee_schedule.csv)。

| 情景 | 单位换手成本（中位） | OOS B0 | OOS B1 | Δ |
|---|---:|---:|---:|---:|
| 仅手续费 | 0.50bp | +0.079 | +0.259 | **+0.180** |
| 手续费 + 1 跳 | 3.47bp | +0.025 | +0.070 | **+0.046** |
| 手续费 + 2 跳 | 6.42bp | −0.030 | −0.117 | **−0.088** |
| 统一 5bp（预注册） | 5.00bp | −0.005 | −0.033 | **−0.028** |

B0 与 B1 的**单位换手成本几乎相同**（3.45 vs 3.44bp），B1 只是换手翻倍、波动减半，
所以它对成本的斜率约为 B0 的两倍。结论：**不要把"负"当成稳健结论，它依赖成本假设。**

## 四条判据

| 判据 | 结果 | 读法 |
|---|---|---|
| **IC**（横截面，辅助） | 门自身 0.0043；带门因子 0.0015 **低于**原始动量 0.0073 | 门在削弱信号，不是筛选 |
| **条件收益**（主证据） | 确认组 5 日 +0.140% vs 未确认组 +0.177%，t = −0.78 | 核心假设方向反了 |
| **置换检验** | 500 次随机门，观测 −0.028 落在零分布内（p = 0.11，95 分位 +0.089） | 无法区分"真门"与"随机少交易" |
| **参数邻域** | 4×3 = 12 格仅 3 格为正，最大 +0.093 | 不是"参数没调好" |

### 换月污染被量化了

主力换月会让 `open_interest` 出现水平跳变：换月窗口内 `|ΔOI_5d|` 均值 **0.525**，
窗口外 **0.112**，相差 4.7 倍。剔除换月窗口后重跑，ΔSharpe 从 −0.028 变成 **−0.174**——
负得更狠。所以污染只会让门"看起来稍好"，而不是制造了这个负结果。

## 方法

| 编号 | 定义 | 作用 |
|---|---|---|
| **B0** | `w = sign(mom60) × 1/N`，5 日调仓，扣费 | 冻结基线：只用价格趋势 |
| **B1** | `w = sign(mom60) × 1/N × 1[sign(ΔOI_5d) = sign(mom60)]` | 处理组：只加持仓确认门 |
| **P1** | 用 `Δvolume_5d` 替代 `ΔOI_5d` 的同一道门 | 安慰剂：增益是否只来自"少交易" |
| **P2** | 逐品种随机置换门标签（保留通过率），500 次 | 零分布与 p 值 |
| **P3** | B1 按 IS 波动率放大到与 B0 同波动 | 排除"低暴露"解释 |

- 收益：`r_t = settlement_t / pre_settlement_t − 1`（同合约结算价，规避换月跳空）
- 趋势：`mom60 = Σ_{k=0..59} log(1 + r_{t−k})`；持仓变化：`ΔOI_5d = OI_t / OI_{t−5} − 1`
- 成本：`cost_t = Σ|w_t − w_{t−1}| × c`，主口径 5bp，敏感性 2/10bp
- 切分：IS 2016–2021 定宇宙，**OOS 2022–2025 只评估一次**（偏离记录见报告 §10）

## 快速开始

```powershell
git clone https://github.com/lavine888/oi-trend-ablation.git
Set-Location oi-trend-ablation
python -m pip install -r requirements.txt

# 平台凭据（不要写进任何文件）
$env:PANDA_DATA_USERNAME = "your-account"
$env:PANDA_DATA_PASSWORD = "your-password"
```

一条命令跑完全流程（取数 → 建面板 → 回测 → 验证 → 落生产 → 回填报告 → 交付门禁）：

```powershell
Set-Location 开发产物
python scripts\run_pipeline.py            # 首次会拉 2016–2025 全量面板
python scripts\run_pipeline.py --reuse-panel   # 之后复用本地面板，几秒钟
```

只想验证代码、不碰平台：

```powershell
python scripts\selftest_engine.py      # 引擎 9 项自检（未来函数/成本/权重口径）
python scripts\mock_panel.py           # 生成合成面板（仅代码验证，不可当绩效）
```

刷新生产产物到最新**已结算**交易日：

```powershell
python scripts\refresh_production.py
```

没有平台账号也能核对：`results/` 里是报告全部数字的原始出处；离线包见
[Release v1.0.0](https://github.com/lavine888/oi-trend-ablation/releases/tag/v1.0.0)。

## 交付门禁

`verify_deliverables.py` 会逐项核对 35 条硬要求，包括：

- 预注册未被事后改动（sha256 一致）
- 面板来自平台接口直取（而非外部 CSV），且覆盖样本内外
- 平台调用留痕存在且含成功返回
- OOS 三变体指标齐全、成本敏感性与盈亏平衡已算、IC 与分层已算
- 未来函数抽检 0 例不一致
- 生产 Parquet 字段合规、主键唯一、信号枚举合法、8 项质量检查全过、写入读回一致
- 报告无 `【待填】` 残留

当前状态：**35/35 通过**（在完整跑过一次 `run_pipeline.py` 的目录上）。
刚 clone 下来的仓库没有 `开发产物/output/`，因此是 **18/35**——未通过的 17 项全部是
"本机还没跑过"这一类，不是结论不一致；跑一次 `run_pipeline.py` 即可补齐。

CI 里跑的是另外两个不依赖平台的关卡：`selftest_engine.py`（引擎 9 项自检）与
`check_report_consistency.py`（报告数字 ↔ `results/` ↔ 预注册哈希 ↔ 生产 Parquet schema）。

## 边界与诚实披露

1. **持仓量不是资金流。** 交易所汇总未平仓合约数无法区分多空开仓方向，也不能折算金额；
   本仓库全程不出现"净流入""主力净多"这类未观测到的量。
2. **成本是近似。** 统一基点模型，缺逐品种手续费与最小变动价位；已给敏感性区间与盈亏平衡点。
3. **基准本身在样本外失效**（IS 0.625 → OOS −0.005）。两个都不赚钱的策略之间比较，
   统计功效有限：本报告的负结论是"没有证据表明有增量"，而不是"已证明增量为负"。
4. **OOS 事实上被评估了 4 次**（格式/工程/数据缺陷修正所致），逐条记录在报告 §10，
   并说明为什么这不构成"看着结果调参"。
5. **复现的样本也偏小**：CFFEX 端只有 5 个品种，横截面很窄；2010–2015 只有 16 个品种。
6. **成本假设决定符号**：统一 5bp 下为负，手续费+1 跳的逐品种口径下约等于零，仅手续费下为正。
   任何"有害/无害"的说法都必须附带成本前提。
7. **平台口径**：本仓库的数据入口是 PandaAI/pandata 数据服务；若你的"QuantStudio"指另一套
   系统，需要换入口重做（见报告 §11）。
