# Alpha-61 数据说明（data_guide）

> 对应《Alpha 因子开发与生产规则 V2》第 4 节要求：数据源、字段、频率、接口限制、清洗口径。
> 本文只描述**平台接口事实**与**本因子采用的口径**，不描述结论。

## 1. 数据入口（平台真实入口）

| 项 | 值 |
|---|---|
| SDK | `panda_data`（PandaAI data 数据拉取库），本地版本 0.0.12 |
| 登录 | `panda_data.init_token(username, password, base_url)`；凭据加密存于 `user.json` |
| 默认网关 | `http://pandadata.pandaaiquant.com` |
| 封装模块 | `开发产物/scripts/pd_client.py`（统一登录、重试、留痕） |
| 调用留痕 | `开发产物/logs/platform_calls.jsonl`：时间、接口、入参、行数、列、日期范围、内容哈希、耗时 |

**不使用**任何个人整理的价格文件、手工表格或第三方爬取数据。面板每次生成都写入
`output/panel_manifest.json`（行数、日期范围、sha1、逐次调用记录），可回溯到具体接口。

## 2. 使用的接口与字段

### 2.1 `get_future_daily`（期货日线）

| 字段 | 用途 | 说明 |
|---|---|---|
| `symbol` | 主键之一 | 主力连续序列，形如 `A_DOMINANT.DCE` |
| `date` | 主键之一 | 交易日 `YYYY-MM-DD` |
| `settlement` | 收益计算 | 当日结算价 |
| `pre_settlement` | 收益计算 | 昨日结算价（同一合约） |
| `open_interest` | **唯一增量来源** | 交易所口径累计持仓量 |
| `volume` | 安慰剂对照 | 当日成交量 |
| `amount` | 流动性过滤 | 当日成交额（元） |
| `underlying_symbol` / `exchange` | 品种/交易所 | 用于分组与披露 |
| `dominant_id` / `trading_code` | 换月追溯 | 当日主力实际合约 |

**收益口径**：`r_t = settlement_t / pre_settlement_t − 1`。
选择该口径的原因：`settlement` 与 `pre_settlement` 属于**同一合约**，换月当日不会产生
连续价格拼接的假跳空；若改用 `close/close` 则必须在换月日做复权或剔除。

### 2.2 接口限制（实测）

| 限制 | 实测值 | 应对 |
|---|---|---|
| 单次查询日期跨度 | ≤ 5 年（错误码 100008） | 分段 2016-2020 / 2021-2025 后拼接 |
| 单次请求体量 | 过大时连接中断（`IncompleteRead`） | 整批失败自动回退为逐品种拉取，失败逐个记录 |
| `get_future_dominant` 参数 | 不接受 `fields`（错误码 100000） | 只传 `underlying_symbol/start_date/end_date` |
| 全市场合约明细 | `get_future_detail` 当前返回体过大导致中断 | 本期不依赖该接口；宇宙由候选清单 + 平台返回情况决定 |
| 席位持仓 | `get_future_symbol_posi` 同样受体量影响 | 本期**不使用**席位数据，避免把「席位净多」误当资金流 |

## 3. 宇宙与清洗口径

| 步骤 | 口径 |
|---|---|
| 候选 | 预注册列出的 53 个境内商品期货品种主力连续序列 |
| 纳入规则（只用样本内判定） | 有效交易日 ≥ 500；样本内日成交额中位数 ≥ 5e8 元；样本内交易日覆盖率 ≥ 80% |
| 剔除 | 平台未返回、或未达上述任一条；逐品种原因写入 `output/universe.json` |
| 缺失 | `settlement`/`pre_settlement`/`open_interest` 任一缺失 → 该品种当日不可交易（权重 0）；不填补、不前向填充 OI |
| 换月 | 使用主力连续序列，收益按同合约结算价计算；不额外做复权 |
| 停牌/无成交 | 由平台日线是否存在该日记录决定；不存在则当日权重贡献 0 |

## 4. 特征口径（全部只用当日及以前）

| 特征 | 公式 | 参数 |
|---|---|---|
| `r` | `settlement / pre_settlement − 1` | — |
| `mom60` | `Σ_{k=0..59} log(1 + r_{t−k})` | 60 交易日 |
| `oi_chg5` | `OI_t / OI_{t−5} − 1` | 5 交易日 |
| `vol_chg5` | `volume_t / volume_{t−5} − 1` | 安慰剂用 |
| `vol60` | `std(r, 60) × √252` | 仅披露，不参与权重 |

**未来函数防线**：信号在 `t` 日收盘后确定，权重从 `t+1` 日起计收益；`validate.py`
用「只用 ≤t 数据重算」抽检，并用「偷看一日」做负向对照。

## 5. 已知边界（必须随结论一起说明）

1. **持仓量不是资金流**。`open_interest` 是交易所汇总的未平仓合约数，只能作「持仓变化
   代理」。它无法区分多头开仓与空头开仓，也无法得出净流入金额。本因子因此**不使用**
   「资金净流入」「主力净多」等表述。
2. **主力连续序列存在换月**。虽然收益按同合约结算价计算，但持仓量在换月日会因合约切换
   出现水平跳变；`ΔOI_5d` 在换月窗口可能失效（见报告的风险识别节）。
3. **成本为近似**。缺少逐品种手续费与最小变动价位时，统一用「成交名义额基点」建模，
   并给出敏感性区间与盈亏平衡成本；不建模冲击成本与保证金占用。
4. **无新闻维度**。平台没有带发布时间的新闻表，本期按预注册直接排除，不用替代数据凑。
